## LevelGen and Survivors



Itch.io : https://characternamenotfound.itch.io/levelgen-and-survivors



Prototype for level generation and ECS-adjacent game loop.

* Level generation uses a noise function (for "terrain"), and graph building (for roads)
* Vampire survivor-like gameplay in process.

  * Basic gameplay elements (weapons, buff items, level-ups, different waves)
  * Centralized game loop (ECS-inspired, but only entities and systems)
  * All Collision checks (except player-to-environment) are performed using manual math, not Unity colliders.

Generation parameters can be adjusted in-game
